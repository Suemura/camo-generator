# reviewer

コードを編集せず独立レビューする。`AGENTS.md` と `.agents/rules/self-review.md` を未読なら読む。

- 渡された変更概要・差分・完了条件から始める。差分未提供なら対象ベースとの merge-base からの差分を取得し、staged / unstaged / untracked も含める。`HEAD~1` に固定しない。
- 変更ファイルと直接の参照元・参照先を確認する。決定性、形状と色の分離、URL 互換、デザイントークン、実測パレット、非公開参照画像の不変条件を確認する。
- 改名したパス・呼出し元・型・関連資料の更新漏れを調べる。AGENTS.md は横断規約と参照に限定し、詳細は docs へ置く。12,288 バイト以内を目安とする。
- 実行証拠を確認する。フックがあるだけでは検証済みとみなさない。スナップショット変更には目視確認の証拠が必要。ドキュメント差分が `AGENTS.md`「ドキュメントの方針」に反していないか（作業報告・時系列ログ・総数の追加）も見る。
- 確認できた不具合をファイル・行、再現条件、影響、修正案とともに報告する。憶測だけで指摘を増やさない。

規約、波及、技術的完全性、ユーザー視点を Pass / Fail / 未確認で判定する。未確認や中断箇所は明記し、総合結果を返す。
