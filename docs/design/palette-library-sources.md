# パレットライブラリ 収録方針と出典

`src/data/palette-library.json` に収録した色の採用方針と、個々のエントリに書けない横断的な判断をまとめる。**各色の出典・実測コマンド・参照画像は各エントリの `source` フィールドが正本**で、ここには重複して書かない。仕様は `docs/02-spec.md` §3.3、迷彩プリセット追加時の登録手順は `docs/04-add-preset.md` §3。

## 収録方針

- 名称・コードは公的規格のみを主キーとする: FS 595 (米連邦規格) / AMS-STD-595A / RAL (独) / BS 381C (英) / RLM / ソ連規格名 (4BO, 7K, AMT) / 日本陸海軍の標準色名 / 防衛省規格 NDS Z 8201E / IDF 慣用名。模型塗料の品番 (Tamiya TS-/XF-, Mr.Color C-) は `note` の「〜相当」に留める。
- 模型塗料のラインナップは**モチーフの索引としてのみ**使う。各塗料が「どの国・軍種・時代のどの標準色を再現したものか」を洗い出し、その標準色を収録対象にする。塗料メーカーの商品名・色名・解説文は引用せず、hex もメーカーサイトからは取らない。
- 公式 sRGB 値が存在しない色は、研究者・模型誌で通説となっている FS 近似色またはマンセル値を経由して換算し、`source` に approx. と明記する。
- アプリの迷彩プリセットの既定色は、公的規格の色番号が存在する色 (M81 / UCP の FS 595 色) は既存エントリで代表させ、存在しない色は `src/core/camo.js` の実測パレットをそのまま「〜 (実測)」エントリとして収録する。
- タグは色味 (hue) / 用途 (use) / 国 (country) の 3 軸。用途タグの camo-* はアプリのプリセットに対応する。
- 収録数は書かない。「100 色以上」で足りる（数値は追加のたびに複数箇所を直す羽目になり、直し漏れで嘘になる）。

## hex の取得元（規格別）

- **FS 595**: GSA が公開する FED-STD-595C の測色データ (D65 CIELab) を sRGB に変換した値。市販の「FS 595 hex チャート」は出典不明かつ相互に食い違うため、一次データ由来の値に統一している。hextoral / e-paint 等が掲載する値とほぼ一致する。595C 未収録の番号 (34087 など) だけは流布しているチャート値を採用し `source` に明記する。
- **BS 381C**: IPMS(UK) の Digital BS381C Colour Chart (W.S. Marshall 2022) 記載の Hex。同 PDF は CIELab / Munsell / NCS を併記しており、scalemates の値と 1 以内で一致する。
- **RLM**: 公式 sRGB 値が存在しないため、同著者の Digital RLM Colours chart (HyperScale 掲載) の Hex を採用し、すべて approx. とした。
- **RAL Classic 現行色**: Wikipedia "List of RAL colours" の Hex。RAL 廃番色 (7028 / 8020 / 7027) は模型塗料の画面近似 (scalemates) を採用し approx. とした。RAL F9 (連邦軍迷彩色) は nuancier-ral の換算値。
- **防衛省規格 NDS Z 8201E**: 規格書記載のマンセル値を Munsell 再表色データ (光源 C) → Bradford 適応 (D65) → sRGB で換算 (colour-science ライブラリ)。
- **日本陸海軍機色・ソ連 AMT 色・IDF 色**: 研究者・模型誌で通説の FS 近似番号を経由し、FED-STD-595C 測色値を変換。すべて approx.。

### 収録を見送ったモチーフ

公的番号も信頼できる換算値も無いもの: 旧海軍工廠別軍艦色 (呉/佐世保/舞鶴/横須賀。マンセル値等の公開一次資料が見つからず)、陸軍戦車色 (土地色/草色/枯草色/土草色。FS・マンセル対照が公開文献に無い)、ソ連 AMT-11 / AMT-12 (FS 近似番号 26190 / 27003 が 595C 未収録)、イタリア Giallo/Verde Mimetico・フランス Vert Armée。

## プリセット実測色

### 登録ルール

- `std` は「<迷彩名> (実測)」。商標名を規格のように見せない（後述「商標・名称について」）。
- `hex` は `PRESETS[key].colors` と完全一致させる。URL には hex しか入らないため、この一致がカラーライブラリ名称の逆引き (`libraryByHex`) の前提になる。
- `code` は公式の色呼称・色番号が一次資料で見つかればそれを入れる（DCU / DBDU の Natick color designation）。見つからなければ index 値の順に `<key>-1`〜 を振る。
- hex は測色データではなく参照画像からの実測値である旨と、実測コマンド・参照画像・ライセンスを `source` に書く。参照画像はライセンスにかかわらず `refs/private/` に置きリポジトリに含めない。
- 実測した hex は「事実の記述」であって画像の派生物ではない。CC BY-SA の参照からの実測値も収録できる（量子化したソース図案は別。`docs/04-add-preset.md` §1）。
- 同じ被服の両面（フロッグスキン）は用途タグを共有し 1 つのタブにまとめる。既存の用途タグと対象が違っても UI 上まとめて引けるほうが使いやすければ同じタグを付けてよい（`camo-flecktarn` は連邦軍車両用 F9 塗料色と被服の実測色の両方に付いている）。
- 文献と実測が食い違ったら実測を優先し、`note` に差異を書く（フロッグスキン ビーチ面は文献では 3 色、実物スウォッチは 4 色）。参照の色被りは補正せず実測値のまま登録する（Auscam のダークグリーンが青緑）。

### 公的な色番号を探して見つからなかった迷彩

いずれも被服の調達仕様は公表されておらず、規格番号・測色値の一次資料が無い。再調査の手間を省くための記録。

- **陸自迷彩 2 型**: 防衛省規格 NDS Z 8201E の `3414 濃緑色(迷彩用)` / `3606 茶色(迷彩用)` は車両・機体の塗料色で被服とは別物（塗料色エントリとして別に収録済み）。防衛省規格目録に「迷彩」を含む規格は無く、被服の色は個別の調達仕様書（非公開）。日塗工番号との公式対応、模型塗料メーカーの公表 hex（タミヤ XF-72 / XF-73 は車両色で、メーカー自身が Web 表示色を「近似」と否認）も無い。生地の実測値は塗料色と 20 以上離れており別色。
- **DPM / DDPM**: 英国防省の被服仕様は非公開、BS 381C にも被服色は無い。
- **CCE**: フランス軍の被服仕様は非公開で、CE 迷彩の 4 色に対応する公的規格番号は見つかっていない。
- **CADPAT / 07 式 / EMR**: カナダ国防省の非公開仕様、中国人民解放軍の内部規格、ロシア国防省の調達仕様で、いずれも公表資料が無い。
- **フロッグスキン**: M1942 の捺染色は当時の Quartermaster Corps の仕様書で定義されているが、Natick color designation に相当する公開データは無い。
- **オーストラリア DPCU**: DEF(AUST) 系の被服仕様は非公開。
- **タイガーストライプ**: ベトナム戦争期の現地製・私物調達が主で統一仕様書が存在しない。
- **NWU Type I**: NAVSUP / Natick の被服調達仕様で規定されるが、FS 595 番号や測色値は公開されていない。
- **ブラッシュストローク / リザード**: ローデシアン・ブラッシュストロークは David Whitehead Textiles による民間設計、TAP47 はフランス軍の被服仕様が非公開。
- **フレックターン系**: 連邦軍の被服色は TL 8305 系の調達仕様で規定されるが、RAL 番号や測色値の一次資料は公開されていない。
- **ベリョースカ / スプリンター / シュトリヒタルン**: ソ連・独・東独側の公的な色番号が確認できない。
- **DBDU の Khaki 384**: 番号はあるが参照画像 (退色した実物写真) で地の Tan 380 と分離できず未登録。`dbdu-tan380` の `note` に記載。

### 実測で判断が要った点

測り方の一般的な罠は `docs/01-tech-verification.md`「参照画像とパレット実測」。ここには色エントリに直接関わる判断だけを置く。

- **ソース図案と同じ量子化重心を採る**（DPM）: `extract-palette.mjs --core` は照明ムラで砂色が明部 / 暗部の 2 クラスタに割れ、k=4 で黒とブラウンが分離しなかった。`gen-src.mjs` の量子化重心（ソース図案と同じ前処理・同じ k-means）を採ると面積比と色の対応が保証される。
- **k を色数より多く取る**（フロッグスキン k=12、ヴュステンターン k=5）: 織り目・陰影、または輪郭のアンチエイリアス（版と版の混色）が 1 つの版を複数クラスタに割る。役割ごとに内部画素数が最大のクラスタを採用する。k を上げても内部画素を持つクラスタ数が増えなければ、それがインクの数の裏付けになる。
- **重ね刷りで生じる 4 色目を版として登録する**（ブラッシュストローク / リザード）: Issue 本文は 3 色だが、k=3 で量子化するとリザードはグリーンが消えてブラウンが 2 クラスタに割れ、ブラッシュストロークは重ね刷り部分がブラウンに吸収されて茶色が広がりすぎる。
- **JPEG のリンギングで測れない色は筆致内部の中央値**（`pla07-brown`）: 細い茶の筆致がリンギングで暗く濁り、k-means の重心が灰側へ流れる。近傍 5×5 がすべて暖色の画素の中央値を採った。
- **k-means が使えない制服写真は色相ゲート**（07 式 海洋）: 4 版 + 襞の影 + 装具が混ざり、小面積の緑が青の影クラスタに吸収される。複数枚の順光部を版ごとの色相条件で集めた中央値を比較し、露出が飽和していない写真の値を採る。`--flatten` は襞のスケールが図案のブロブ幅と同程度で使えない。
- **小面積色には `--core` が必須**（NWU Type I のダークネイビー約 4%）: 素の k-means 重心だと地色との混色に吸収されて持ち上がる。
- **布地写真の色被りは実測に使わない**（ヴュステンターン）: 布地写真は照明が青寄りで彩度が失われ、タン地が無彩色として出る。色は平坦なベクタースウォッチから採り、布地写真は形状・疎密の比較にのみ使う。
- **配色替えの版と色の対応は画素単位の交差集計で決める**（フレックターン変種 8 種）: Wikimedia Commons の各国スウォッチ（User:Skjoldbro）は同一ベクター図案の色替えだが明度順を保存していない。ドイツ配色版（ベルギー空軍がそのまま使った Belgian Flecktarn）と各変種を最近傍リサイズで同寸に揃えて量子化し交差集計する。3 色版 6 種は 5 版を {地} / {グリーン + レッドブラウン} / {ダークグリーン + ブラック} の 3 群に統合した色替えで、群の切り方が全種で同一。`note` に元の版との対応を書く。
- **Issue 記載の色が参照と食い違うことがある**（07 式 海洋の「濃紺」「ライトブルー」は襞の影と様式化スウォッチの解釈）: 実物の版構成は参照の実測で確定する。
- **名称の混同**（ヴュステンターン）: Wikipedia は「Wüstentarn はしばしば誤って Tropentarn と呼ばれる」と注記しており、Commons の "Tropentarn" 名のスウォッチも 3 版しか持たない。実測した版数に従い 3-Farben-Tarndruck = ヴュステンターンとして登録。5 色の本来のトロペンターンは信頼できる参照がなく未登録。
- **国タグ**: 迷彩を制定した当時の国名で示す（ローデシア `rh` は ISO 3166-1 から削除されたコードだが採用）。

## 注意事項

### hex 値の近似性

- 規格色はいずれも物理的な色票 (チップ) で定義されており、sRGB 値は照明条件・変換式に依存する近似値である。本ライブラリは D65 光源・sRGB (D65) 前提で統一した。
- FS 34087 Olive Drab は 1974 年に FS 34088 へ改番され FED-STD-595C には収録されていないため、この 1 色のみ一次データではなく流布している hex チャートの値を採用している。
- RAL 8027 / 9021 (F9 迷彩色) はマット専用色で、変換元によって明度差が大きい (9021 は #151618 〜 #3e3f3c)。用途上は「ほぼ黒」で問題ないが、他源との突合時は留意する。
- RAL 8020 / 7027 (アフリカ軍団色) は 1961 年に RAL から削除されており、換算値は模型塗料の画面近似に依存する。特に 7027 は資料間で #a5936c〜#c1b396 と明度差が大きい。
- RLM 色は戦時中の色票が現存せず、RLM 65 (#9cd8e6) はチャート値の彩度が他の資料 (#93b1b1 前後) より明らかに高い。RLM 81 は文献により褐色〜緑褐色まで解釈が割れ、チャートの V1 値を採用した。RLM 83 は近年の研究 (Ullmann) で暗青色であったとされるが、本ライブラリでは模型界で長く流布した「ダークグリーン」解釈の値を収録し、名称にその旨を付記した。
- 4BO は 1941 年当時の塗料自体に大きな個体差があり、FS 34102 近似はあくまで通説の一つ (FS 34095 / 34082 説もある)。7K も同様。
- 日本陸海軍機の色は現存塗膜・文献の再解釈が続いている分野であり、FS 近似は模型用途の慣例値に過ぎない。特に海軍暗緑色 D1 は実物のほうが青緑味が強いとの指摘がある。日本海軍 暗緑色 (中島系) は FS 34077 近似が通説だが 595C には 34077 が無いため、同色相・艶有の 14077 の測色値で代用した。灰緑色 J3 も同様に 16350 の値を使っている。
- 海自艦艇色 2704 / 2705 はマンセル N5 / N4 (無彩色) の規格値からの換算で、色相のブレは無いが実艦は青味を帯びて見えることが多い。陸自 OD 色はマンセル値 7.5Y 3/1 のみが規格化されており、sRGB 換算は参考値。
- IDF 色は公的規格が無く、FS 30372 (1961〜73) / FS 36134 (1982〜) はいずれも模型考証上の近似番号である。
- プリセットの実測値は参照写真の露出・布地の退色に依存するため、規格値ではない。スプリンターの実測値は実物スウォッチではなく図案を再描画した参照画像からの抽出で、実物の染色個体差・退色は反映していない。

### 商標・名称について
