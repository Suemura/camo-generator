# v25: 陸自迷彩 2 型風（JGSDF Type II）プリセットの追加（Issue #28、2026-09-04）

### 目的

陸上自衛隊 迷彩 2 型（1991〜）を追加する。米軍以外・国産迷彩としての初出。実物の特徴は
「M81 より丸く小ぶりなブロブ」「ブロブの輪郭から小さなローブ（斑点）が多数分岐する二重構造」
「4 色（タン / グリーン / ブラウン / 黒）で、遠目にざらついて見える」。

### 手法の選択: ドット層の追加ではなく専用ソース図案 1 本

Issue の当初案は「ブロブ層 `genQuilt`（小 `patchR`）＋ 座標ハッシュのドット層の 2 層合成」だった。
実際には**ドット層を実装していない**。クイルトは「局所形状 = ソース図案そのもの」なので、
斑点は図案側に最初から含まれており、専用ソース図案 1 本で二重構造がそのまま再現される。
ドット層を別に足すと (a) 図案由来の斑点と重複し、(b) `cleanupFragments` / 多数決ミップとの
相互作用を新たに検証する必要が生じ、(c) Issue #24 のチョコレートチップ小石層と
パラメータ袋の共通化問題を抱え込む。既存手法の範囲で目標の見え方が出たので追加しない。

### リファレンス画像（布地の写真をソースにするための前処理）

`refs/jgsdf2.jpg` — Wikimedia Commons [File:迷彩服2型の迷彩パターン.jpg](https://commons.wikimedia.org/wiki/File:%E8%BF%B7%E5%BD%A9%E6%9C%8D2%E5%9E%8B%E3%81%AE%E8%BF%B7%E5%BD%A9%E3%83%91%E3%82%BF%E3%83%BC%E3%83%B3.jpg)
（1280×960、Crescent moon 撮影、CC BY 3.0）。既存の 7 プリセットと違い**フラットなスウォッチではなく布地の接写写真**で、
そのまま量子化すると 2 つの形で破綻した。対策として `tools/` に前処理オプションを追加した（いずれも既定オフ、
既存の生成物は byte 一致を確認済み）。

1. **織り目（ツイルの斜め筋）が色の分散として効く** → `--blur=SIGMA`（`tools/gen-src.mjs`）。
   原寸 1280px で k=4 量子化すると `#989689 / #747d6a / #5c6251 / #41423a` となり**茶が緑に吸収されて消える**
   （k-means が設計色ではなく明度で切る）。`--resize=800 --blur=1.2` で `#8f8c7f / #60775e / #765450 / #464e46` に収束し、
   RLE のラン数も 117034 → 19494 に減った
2. **周辺減光が最も暗い値へ丸ごと量子化される** → `--flatten=SIGMA`（`tools/gen-src.mjs` / `tools/extract-palette.mjs`、
   実体は `tools/image.mjs` の `flatten()`。強くぼかした自分自身で割って全体平均へ正規化するフラットフィールド補正）。
   補正前は四隅の減光が値 3（黒）に落ち、**黒の面積比が 10.5% → 21.5% に膨らんで**出力の黒が実物より
   はるかに大きな塊になっていた。`--flatten=80` で解消。sigma は 40 / 80 が有効、120 では照明成分の推定が
   図案そのものを含んでしまいパレットが縮退する
3. **輪郭のアンチエイリアスがパレット重心を隣接色へ引く** → `--core[=R]`（`tools/extract-palette.mjs`）。
   斑点が多い図案では素の k-means 重心だと黒が `#464e45`（緑寄り）になり実物と合わない。
   半径 R の近傍が全て同ラベルの画素だけで中央値を取ると `#46444b` になる

生成コマンド:

```bash
node tools/gen-src.mjs refs/jgsdf2.jpg src/core/jgsdf2src.js 4 JGSDF2 --resize=800 --blur=1.2 --flatten=80
node tools/extract-palette.mjs refs/jgsdf2.jpg 4 --core --flatten=80
```

`src/core/jgsdf2src.js`（生成物、800×600、base64 23.6KB / ファイル 24KB）は m81src（24KB）と同等なので静的 import。

### パラメータの根拠

- `kBase: 1.1` — ソース図案（800px）を 1/1.1 に縮小参照する。実物と同じ「512px の画面にブロブが 6〜7 個」の
  見え方になる倍率。1 未満（= ソースの拡大参照）にすると最近傍サンプリングで輪郭が階段化するため 1 以上に留める。
  多数決ミップの発動域（`k > 1.4`）にも入らない。当初 640px ソース + `kBase 1.25` で試したが、実物より細かく写り、
  実物のスケールに合わせて `kBase 0.875` にすると階段化した。**ソースの解像度を上げて kBase を 1 以上に保つ**のが正解
- `patchR: 185` — ソースが M81 と同じ 800px なので M81 と同値でパッチ / キャンバス比が揃う。
  `tests/tiling.test.ts`（閾値 1.8、変更なし）に合格
- `frac: [0.240, 0.468, 0.186, 0.105]` — ソース図案の実測面積比（`gen-src.mjs` の出力）
- `divw: [1, 1, 1, 1.6]` — 黒は面積が小さい（10.5%）ので M81（2.4）ほどではないが重みを足す。
  1 のままだと完走が大面積色を優遇する性質（v18 / v19 の残課題と同根）で黒がさらに痩せる
- `colors` — `#8d8b7f` / `#5e775c` / `#74524e` / `#46444b`（上記の実測コマンド）

### 検証

- 目視: seed 1234 / 777 / 211025 × scale 0.7 / 1.0 / 1.5 / 2.0（512px）、`--compare` で実物と並置、
  `--tile` の 2×2、`--size=2048x2048 --crop=512` の等倍クロップ。既知アーティファクト
  （ブロック感・境界急変・切断面・鏡映対称・市松ノイズ・微小点）の再発なし
- 等倍クロップ（2048px、`k = 0.275`）の輪郭の階段は woodland を同条件でレンダしたものと同程度で、本プリセット固有の悪化はない
- タイル 2×2（seed 1234）で継ぎ目視認不可。`tests/tiling.test.ts` は閾値変更なしで合格
- 性能: 512px 1.6〜1.9s（woodland と同等）
- スナップショットは `jgsdf2` の 1 行追加のみ。既存プリセットのハッシュは不変

### origin/main（v20〜v24）取り込み後の再検証

本 PR の作業中に CCE（v20〜v23）と DBDU（v24）が main に入り、v23「下刷りの埋め方を多数決膨張に変更」で
`genQuilt` の共通経路が変わった。マージ後に `jgsdf2` のハッシュだけが変化したため（他 8 プリセットは main と一致）、
seed 1234 / 777 / 211025 × scale 0.7 / 1.0 / 1.5 / 2.0、`--compare`、`--tile`、`--size=2048x2048 --crop=512` を
再レンダして目視した。**見た目の差は認められず**、v23 が根絶した「平行な細線」も本プリセットでは元から出ていない。
既知アーティファクトの再発もないため、パラメータは変更せずスナップショットのみ更新した。

### 残課題

- 黒の塊が実物よりやや大きく連続しがち。実物は独立した「クローバー状のクラスタ」として散る。
  完走 / 撤回の非対称（v18 の残課題）が効いており、`divw` では形の分散までは制御できない
- `--flatten` はコントラストをわずかに落とすため、パレット実測値も補正後の色になる。
  スウォッチ画像が手に入れば補正なしで測り直す価値がある
